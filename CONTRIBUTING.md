# Как вносить изменения

1. Задача начинается с записи: ADR для архитектурного решения
   (`docs/adr/NNNN-*.md`), иначе короткое описание в PR.
2. Ветка от `main`, один плагин или одна тема на PR.
3. Перед PR: `pnpm run check` и `pnpm run build` зелёные; у изменённого
   плагина обновлены `README.md` и `PLUGIN_OVERVIEW.md`.
4. Копия встроенного плагина bb: сначала коммит переноса апстрима с обновлённым
   `UPSTREAM.md`, затем коммиты своих правок.
5. Релиз плагина: поднять `version` в его `package.json`, тег
   `<plugin-id>/vX.Y.Z`, при необходимости обновить диапазон в
   `marketplace/marketplace.json`.
