# Боты 1ma и блок ботов в боковой панели: решения владельца

14.11.2026. Задача передана чатом «Суперагент» чату «bb -> 1ma»; начинаем
отдельным тредом, когда на Linux поднимут лимит памяти (сейчас все треды
делят 3 ГиБ, см. заметку о лимите).

## Решения владельца

- Два своих плагина: `1ma-bots` (бот как сущность) и `1ma-sidebar` (боковая
  панель 1ma). Владелец будет дорабатывать оба.
- Боты архитектурно готовы к любым задачам: разработка, маркетинг,
  бухгалтерия. Просто и эффективно. Сначала изучить лучшие практики, в том
  числе как это сделано у ботов Grok, и брать готовое по максимуму, а не
  писать с нуля.
- Первая версия панели: боковая панель ровно как сейчас (та же на Mac и на
  Linux), а между кнопкой New Thread и первым проектом — блок ботов.
  Дальнейшие доработки панели — отдельно, после того как владелец увидит
  первую версию.
- Вид блока ботов на старте берём с готового плагина (Bots Sidebar), потом
  владелец скажет, что переделать. У Bots Sidebar нет лицензии: повторяем
  вид и устройство, код не копируем. Код с открытой лицензией (Cursor
  Sidebar, MIT) можно брать с указанием авторства.
- Работа по этапам, каждый с согласия владельца и ревью Codex: описание и
  макет → `1ma-bots` → `1ma-sidebar` → перенос ботов из Bots Sidebar и
  установка на Linux и Mac; сторонние плагины удаляются после приёмки.

## Что уже известно

- Шов с суперагентом: RPC `bots.v1.forThread({threadId})` — бот чата (id,
  имя) и его возможности, либо пусто; при необходимости `bots.v1.list`.
  Описан в `docs/adr/0006-superagent.md` (ветка `superagent`); изменение —
  через чат «Суперагент» и правку ADR.
- Счётчик «ждёт вас» — штатное состояние чатов бота (вопрос инструментом
  вопросов 1ma); чаты бота с вопросами не скрывать, иначе нет уведомлений.
- Пересылка между ботами по кругу ограничивается в коде, не текстом промпта.
- Точки расширения: `app.slots.navPanel` (один пункт навигации на плагин,
  набор задаётся кодом), `experimental_threadList` и
  `experimental_sidebarNavigation` (исключительные, заменяют панель);
  `bb.agents.configure` и `contributeInstructions` для роли и памяти
  (до 32 768 символов, применяются при следующей сессии провайдера).
  Bots Sidebar 1.1.0 (`ff58530`): состояние в базе плагина, в промпт не
  больше 4 096 символов, память с проверкой хеша.
- На Linux сейчас стоят Bots Sidebar 1.1.0 и Cursor Sidebar 0.3.5; какая
  панель включена у владельца — проверить по снимку экрана.
- Временные серверы 1ma на этой машине не поднимать; проверка вида и
  сквозные проверки — в GitHub Actions.
