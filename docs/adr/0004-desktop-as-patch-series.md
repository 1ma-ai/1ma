# ADR-0004. 1ma Desktop — серия правок поверх выпусков bb

Статус: принято 2026-10-31

## Контекст

Владелец решил делать собственное приложение 1ma Desktop сейчас (этап 5a
плана). Приложение bb Desktop живёт в монорепозитории bb вместе с сервером,
демоном и веб-частью; его имя, иконки, канал обновлений, папка данных и
настройки по умолчанию лежат в нескольких файлах (см.
`docs/plan/2026-10-31-1ma-desktop.md`). bb выпускает десктоп часто, теги
`desktop-vX.Y.Z`.

## Решение

- 1ma Desktop собирается из точного выпуска bb (`desktop/upstream.json`) и
  короткой серии правок `desktop/patches/` плюс подмены ассетов. Код bb в
  репозиторий 1ma не копируется, форк репозитория bb не создаётся.
- Правки небольшие и тематические, каждая сохраняет тесты bb зелёными;
  изменённые тесты входят в ту же правку.
- Сборка, тесты и смоук-тест упакованного приложения идут в GitHub Actions на
  машинах GitHub (`.github/workflows/desktop.yml`), начиная с macOS arm64 без
  подписи.
- Выпуски публикуются в релизах репозитория `1ma-ai/1ma` с тегами
  `desktop/v<версия bb>-1ma.<номер сборки>`; канал обновлений приложения
  указывает туда же.
- Порт сервера не меняем (38886): при переходе владелец не запускает bb и 1ma
  одновременно. Папка данных своя (`~/.1ma`), поэтому данные не смешиваются.
- Видимые строки «bb» в интерфейсе (их тысячи) меняются не ручной правкой, а
  отдельным автоматическим преобразованием при сборке с проверкой, которая
  находит оставшиеся упоминания. Это следующий шаг.

## Последствия

- Видно ровно то, что изменено; переход на новый выпуск bb — смена тега и,
  при конфликте, перенос коммитов серии.
- Репозиторий 1ma остаётся маленьким. Сборка требует сети и машин GitHub;
  для публичного репозитория это бесплатно.
- Без подписи Apple первый запуск идёт через «Открыть всё равно», а
  обновления на Mac ставятся вручную. После покупки Apple Developer ID
  правка 4 удаляется.
- Отклонено: форк репозитория bb на GitHub (форк публичного репозитория нельзя
  сделать приватным, история bb тянется целиком, правки размазаны по истории).
