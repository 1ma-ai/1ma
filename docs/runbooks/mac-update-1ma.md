# Обновить 1ma на Mac (инструкция для Codex)

Пока 1ma не подписан сертификатом Apple, macOS не даёт приложению заменить
себя: 1ma только сообщает о новой версии (Settings → Updates). Новую сборку
ставит Codex владельца по этой инструкции; она подходит для любой версии,
номер берётся из файла, который смотрит само приложение.

```text
Задача: обновить приложение 1ma на этом Mac до последней опубликованной сборки. Данные 1ma (~/.1ma) не трогать: они остаются как есть.

Правила:
- Команды выполнять вне песочницы Codex.
- Не отключать Gatekeeper и SIP, не снимать атрибут карантина — только кнопка «Open Anyway» в настройках, если macOS спросит.
- Если что-то не совпадает с описанием (суммы, версии, ошибки) — остановиться и прислать вывод владельцу.

Шаг 1. Узнать последнюю версию и текущую:
curl -fsSL https://github.com/1ma-ai/1ma/releases/download/desktop-latest/desktop-version.json | grep '"version"'
~/.1ma/bin/bb --version
Если версии совпадают — обновлять нечего, сообщить владельцу.

Шаг 2. Скачать сборку и проверить сумму (V — версия из шага 1):
mkdir -p ~/1ma-update && cd ~/1ma-update
curl -fLO "https://github.com/1ma-ai/1ma/releases/download/desktop/vV/1ma-V-arm64.dmg"
curl -fLO "https://github.com/1ma-ai/1ma/releases/download/desktop/vV/SHA256SUMS"
grep " 1ma-V-arm64.dmg$" SHA256SUMS | shasum -a 256 -c -
Должно быть «1ma-V-arm64.dmg: OK».

Шаг 3. Дождаться, пока в 1ma не работает ни один тред, и выйти из 1ma (Cmd+Q). Проверить:
pgrep -lf "/1ma.app/" ; lsof -nP -iTCP:38886 -sTCP:LISTEN
Обе команды ничего не выводят.

Шаг 4. Открыть 1ma-V-arm64.dmg, перетащить 1ma в Applications с заменой, извлечь образ. Открыть 1ma; если macOS скажет, что не может проверить приложение — System Settings → Privacy & Security → «Open Anyway».

Сразу после первого запуска следить за окном macOS «1ma хочет получить доступ к файлам в папке „Рабочий стол“» (или «Документы», «Загрузки») и нажать «Разрешить». Пока сборка не подписана Apple, macOS считает каждое обновление новым приложением и спрашивает заново; без ответа 1ma ждёт: так 13.11.2026 сборка плагина `msg8-release-hooks` с Рабочего стола стояла 151 с и в следующий раз больше 5 минут. Если окна не видно, а плагины в 1ma долго в состоянии запуска — проверить, не спрятано ли окно за другими.

Шаг 5. Проверить: ~/.1ma/bin/bb --version печатает V; треды и проекты на месте; новый тред отвечает; Linux-сервер в меню Server открывается. Если macOS заново спросит разрешения (микрофон, управление компьютером) — дать их.

Шаг 6. Удалить ~/1ma-update и сообщить владельцу версию до и после.
```
