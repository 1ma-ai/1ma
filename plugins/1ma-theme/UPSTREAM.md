# Источник значений

Токены в `themes/1ma.css` скопированы из `apps/app/src/components/ui/theme.css`
репозитория bb (https://github.com/get-bb/bb), коммит
`a1bf55b6a04c7948ae5ae0dcfcbdec27d2b507a2` от 2026-10-29 (bb 0.48.1).

Скопированы только документированные токены темы (якоря, акцент, уровни
текста, семантические цвета, радиус, шрифты, палитра терминала). Остальные
токены bb выводит из якорей сам, поэтому они не фиксируются.

При обновлении bb: сравнить эти токены с новой версией файла и перенести
изменения отдельным коммитом, не смешивая с правками 1ma.
