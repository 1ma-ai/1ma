Компактная доска задач под композером на домашнем экране bb.

## Что даёт

- Три полосы: **Needs you** (ждёт вас: вопрос агента, ошибка, упавшая очередь),
  **Running** (идёт выполнение или фоновая работа), **Done** (отмечено сделанным
  в Focus Board).
- На домашней странице проекта показывает только его треды, на общей — все.
- Клик по карточке открывает тред.

## Как работает

Читает живой список тредов через SDK (`experimental_useSidebarThreads`) и
отметки «сделано» через RPC `done_list` плагина Focus Board. Своей базы и
хранилища в браузере нет; отметки перечитываются каждые 20 секунд, потому что
realtime-событие Focus Board доступно только ему самому. Focus Board должен быть
включён на том же сервере bb.
