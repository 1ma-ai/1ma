# Источник

Копия встроенного плагина `plugins/thread-list` репозитория bb
(https://github.com/get-bb/bb, MIT, Copyright (c) 2026 Michael Yong), тег
`desktop-v0.49.0`, коммит `7b26cae79ec978fafd0a5db0e8517e94f12eb8f4`
(«Prepare bb-app 0.49.0 (#7196)»), снята 14.11.2026.

Копия сделана процедурой bb для копируемых встроенных плагинов
(`docs/forkable-plugins.md`, `scripts/lib/plugin-fork.mjs` того же
коммита) командой

```sh
node scripts/fork-bb-plugin.mjs --bb <checkout bb на этом коммите> --plugin thread-list --out <пустой каталог>
```

Она копирует каталог плагина, кладёт рядом компоненты реестра bb, которые
он импортирует (`components/`, `lib/`, `hooks/`), направляет `@/*` на
`./*` и заменяет пакеты рабочего пространства bb пакетами npm.

Правки 1ma лежат отдельными коммитами после коммита копии. Свой код —
в каталоге `1ma/`; в файлах bb только точки подключения.

## Обновление на новый выпуск bb

1. Снять копию той же командой с нового тега в пустой каталог.
2. Заменить ею файлы bb в этом каталоге одним коммитом «перенос апстрима»,
   не трогая `1ma/` и этот файл.
3. Отдельным коммитом вернуть точки подключения 1ma (их список — в
   `1ma/README.md`) и прогнать тесты копии и свои.
