# Код 1ma в копии штатного списка чатов

Свой код 1ma лежит здесь; файлы bb в копии меняются только в точках
подключения ниже. При переносе нового выпуска bb (см. `../UPSTREAM.md`)
эти точки возвращаются отдельным коммитом.

## Что делает

- `BotsBlock.tsx` — блок «Bots» над проектами.
  - Заголовок — заголовок группы bb (`TopLevelSidebarSection`) со
    штатной кнопкой нового чата (`SidebarControlButton`, «New bot»).
  - Бот нарисован строкой родительского чата bb. Слева лицо на месте
    значка чата, справа от него имя и сразу штатная стрелка
    (`SidebarChildToggleChevron`), второй строкой роль, как в Bots
    Sidebar. Щелчок по строке открывает главный (первый открытый)
    разговор.
  - На лице состояние:
    - на углу — значок bb для главного разговора;
    - точки — сколько других разговоров работает: больше трёх
      показываются как две точки и «+», точное число в подсказке;
    - красный «!» — непрочитанная ошибка в другом разговоре.
      Состояние каждого разговора считает `experimental_resolveThreadStatus`,
      как в строках bb.
  - При наведении штатные «+» (новый разговор в композере bb через
    `bots.v1.startThread`) и «…»: новый разговор, настройки бота, скрыть
    или вернуть бота (`bots.v1.setHidden`).
  - Разговоры бота — дерево bb (`ProjectThreadTree`, `depthOffset: 1`)
    под штатной линией (`ThreadTreeGroupLine`), под ними «Done: N».
  - Внизу блока строка «N hidden»: она показывает скрытых ботов
    приглушёнными и без разговоров, их разговоры остаются в проектах.
  - Чат из списка перетаскивается на бота (`thread-drop.ts`): на лицо —
    станет первым разговором бота, на остальную строку — последним.
    Строка подсвечивается и подсказывает, куда ляжет чат. После переноса
    появляется уведомление «Open», бот раскрывается и прокручивает к чату.
  - Свёрнутые боты хранятся в синхронизируемой настройке `collapsedBots`,
    как свёрнутые чаты bb; по умолчанию боты раскрыты.
- `use-bots.ts` — одно решение для блока и для фильтра проектов: блок и
  вынос чатов бота включены, только если установлен `1ma-bots` (есть его
  пункт навигации), настройка «Show bots» включена и список ботов прочитан.
  Иначе список ровно штатный.
- `bot-threads.ts` — какие чаты уходят из проектов: чаты видимых ботов с
  потомками; чаты скрытого бота остаются в проектах.
- `server.ts` — настройка «Show bots» и однократный перенос настроек
  штатного списка (`thread-list` → `listPreferences`). Удался при
  загрузке — старые `sidebar.*` не переносятся вовсе; штатный список ещё
  не загружен (bb грузит плагины по id) — перенос при первом чтении
  заменяет всё, кроме ключей, которые владелец выбрал здесь (RPC или CLI).
  Штатного списка нет или он выключен — перенос не считается сделанным, и
  старые `sidebar.*` переносятся как обычно.
  Ещё при запуске один раз выбирает эту панель списком по умолчанию:
  только если `sidebar.threadListProvider` никто не сохранял (ревизия 0),
  записью с `expectedRevision: 0`; любой сохранённый выбор остаётся.
- `bots-rpc.ts` — часть контракта `bots.v1` плагина `1ma-bots`, которую
  читает панель.

## Точки подключения в файлах bb

| Файл                                                         | Правка                                                                                                                                                                                                                                         |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `package.json`                                               | имя `bb-plugin-1ma-sidebar`, описание, `engines`                                                                                                                                                                                               |
| `app.tsx`                                                    | заголовок слота «1ma Sidebar»                                                                                                                                                                                                                  |
| `server.ts`                                                  | `register1maSidebar(bb, createPreferenceStore(bb))` даёт `store`, который помнит выбор владельца; `chooseDefaultThreadList()` и `copyBuiltInPreferences()` при загрузке (после успеха старые `sidebar.*` не переносятся) и в `listPreferences` |
| `app/model/use-sidebar-data.ts`                              | `useWithoutBotThreads(...)` вокруг `experimental_useSidebarThreads`                                                                                                                                                                            |
| `app/list/ProjectList.tsx`                                   | `<BotsBlock … />` после `<SidebarDraftPresenceSync />`, ему передаются штатные `collapsedThreadIds`, `collapsedEnvironmentIds` и их переключатели                                                                                              |
| `app/list/ProjectRow.tsx`                                    | `ProjectThreadTree` принимает `depthOffset` (вложенное дерево получает отступ и шаг строк подчатов), `ThreadTreeGroupLine` экспортирована                                                                                                      |
| `shared/preferences.ts`                                      | ключ `collapsedBots`: свёрнутые боты и весь блок (`bots`)                                                                                                                                                                                      |
| `app/dnd/useSectionThreadDnd.ts`                             | перетаскивание bb сообщает `botDrop` (`1ma/thread-drop.ts`), какие чаты несёт и где указатель; над ботом у списка нет своих мест для сброса                                                                                                    |
| `shared/preferences.ts`, `app/rows/ThreadRow.tsx` и их тесты | ключи `1ma-sidebar/move`, `1ma-sidebar/customizeRowActions`                                                                                                                                                                                    |
| `skills/1ma-sidebar/SKILL.md`                                | имя навыка `1ma-sidebar`, команда `bb 1ma-sidebar`                                                                                                                                                                                             |
| `vitest.config.ts`                                           | `maxWorkers: 2`, имя проекта                                                                                                                                                                                                                   |
| `tsconfig.json`                                              | `1ma/**` в `include`                                                                                                                                                                                                                           |
| `PLUGIN_OVERVIEW.md`                                         | описание плагина 1ma                                                                                                                                                                                                                           |
