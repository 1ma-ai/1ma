# 1ma Bots

Плагин 1ma: бот как ИИ-сотрудник — имя, роль, лицо, инструкции, своя
память, области работы и свои чаты. Описание и решения владельца:
`docs/plan/2026-11-14-1ma-bots-and-sidebar-design.md`.

## Устройство

- `server.ts` — подключение к 1ma: таблицы в базе плагина, RPC `bots.v1.*`,
  настройка агента в чатах бота, инструменты, хук отправки, события чатов,
  расписание автоотметки «готово», CLI `bb 1ma-bots list`.
- `src/store.ts` — боты, чаты ботов, журнал действий, токены начала чата.
- `src/letters.ts` — письма между ботами: проверка «кому можно писать»,
  цепочка писем и её лимит, лимит в час; всё в одной транзакции.
- `src/memory.ts` — правка памяти по фактам и целиком по хешу.
- `src/contract.ts` — контракт RPC, общий для сервера и интерфейса.
- `app.tsx`, `src/ui/` — страница «Боты» и строка «Бот» в карточке чата.
- `components/ui`, `lib`, `hooks` — компоненты реестра bb (`REGISTRY.md`).
- `strings.ts` — все тексты для людей и агентов в одном месте.

## Шов с суперагентом

`bots.v1.forThread({ threadId }) → { botId, capabilities } | null`. Чат,
начатый из бота, создаёт сервер этого плагина (`originPluginId:
"1ma-bots"`), и привязка появляется до первого хода: токен начала чата
лежит в метаданных плагина и проверяется по таблице `pending_starts`.
