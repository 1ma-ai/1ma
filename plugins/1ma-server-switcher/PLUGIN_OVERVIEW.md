Переключатель серверов bb для десктоп-приложения.

## Что даёт

- Выпадающий список «Mac / Linux» рядом с кнопкой сайдбара: переключает
  десктоп-приложение между уже сохранёнными подключениями к серверам bb.
- Показывает состояние подключения и ошибку, если переключение не удалось.
- Скрыт, когда приложение не десктопное или сохранено меньше двух серверов.

## Как работает

Оверлей приложения (`experimental_appOverlay`) читает список подключений из
моста bb Desktop (`window.bbDesktop`) и вызывает его `selectServer`. Данные
серверов не пересылаются и не сохраняются.
