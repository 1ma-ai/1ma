# Mac / Linux server switcher

Оверлей для bb Desktop: переключение между сохранёнными подключениями к
серверам bb одним выпадающим списком рядом с кнопкой сайдбара. В браузере и при
одном сохранённом сервере ничего не показывает.

## Разработка

```sh
pnpm install            # из корня репозитория
pnpm --filter 1ma-server-switcher run typecheck
pnpm --filter 1ma-server-switcher run build   # bb plugin build → dist/
```

Компонент зависит от моста `window.bbDesktop`, который даёт только
десктоп-приложение, поэтому его поведение проверяется вживую в 1ma Desktop с
двумя серверами; подписи серверов (`labels.ts`) покрыты тестами.

## История

Написан владельцем 1ma (октябрь 2026), перенесён в монорепо без изменений
поведения. Переименован в `1ma-server-switcher` при ребрендинге 30.10.2026.

0.2.1 (01.11.2026): два сервера с одинаковым коротким именем («Linux prod» и
«Linux staging») показываются полными именами; положение пересчитывается не чаще
раза за кадр, а не на каждое изменение страницы; у списка видимая рамка фокуса
с клавиатуры; тексты собраны в `strings.ts` без изменения формулировок.
