# Бренд 1ma

Роли: пиксельный человечек — favicon и иконка приложения, «1ma» — логотип.

`source/` — оригиналы от владельца, вручную не правятся:

- `app-icon.png` — пиксельный человечек, 1254×1254, чёрный фон, 31 белый
  квадрат.
- `logo.svg` — логотип «1ma» в контурах.

`archive/` — прежний favicon со знаком «1», заменён 31.10.2026.

Всё остальное собирается из оригиналов скриптом без внешних зависимостей:

```sh
python3 -I scripts/brand/make-icons.py          # записать ассеты
python3 -I scripts/brand/make-icons.py --check  # проверить актуальность (CI)
```

| Файл                                                              | Что это                                                                      |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `app-icon-1024.png`                                               | иконка приложения по сетке macOS: плитка 824 px на прозрачном холсте 1024 px |
| `1ma.icns`                                                        | та же иконка для macOS во всех размерах 16–1024                              |
| `plugins/1ma-brand/assets/favicon-*.png`                          | favicon: плитка с человечком, 16 и 32 px                                     |
| `plugins/1ma-brand/assets/app-icon-*.png`, `apple-touch-icon.png` | иконки для установки как приложения                                          |
| `plugins/1ma-brand/assets/icon.svg`                               | человечек в векторе из 31 квадрата; иконка плагинов и маркетплейса           |
| `plugins/1ma-brand/assets/wordmark.svg`                           | логотип «1ma»                                                                |
| `marketplace/icons/1ma.svg`                                       | иконка маркетплейса 1ma, копия `icon.svg`                                    |

Новая версия оригинала: положить файл в `source/` под тем же именем, запустить
скрипт, проверить картинки глазами и закоммитить всё вместе.
